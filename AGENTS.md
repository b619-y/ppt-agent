# PPT Agent project instructions

When creating or editing a scientific presentation in this repository, follow [`风格规范.md`](风格规范.md) and the `$ppt-agent` skill in [`.agents/skills/ppt-agent/SKILL.md`](.agents/skills/ppt-agent/SKILL.md).

- Keep original research PDFs and user data under `input/`; deliver each project under `output/<topic>/`. Both folders are git-ignored.
- Use primary papers and official reports. Do not invent or estimate values. Record the source, figure/table, PDF page, and printed page for every figure or datum.
- All new text in generated slides and charts uses Microsoft YaHei. Text embedded in source figures is unchanged.
- The standard slide script supports two evidence images. Use a suitable custom layout when evidence requires a third panel.
- Show one sample slide for approval before producing a full deck. Inspect rendered previews visually before delivery.
